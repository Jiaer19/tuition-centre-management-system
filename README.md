# Tuition Centre Management System
A Java GUI-based Tuition Centre Management System developed as part of a two-member group assignment for the Object-Oriented Programming module at Asia Pacific University (APU).

## Features
- User Authentication
- Role-Based Access Control
- Student Management
- Tutor Management
- Receptionist Management
- Payment Processing
- Schedule Management
- Monthly Income Report
- Subject Request Approval Workflow

## Technologies
- Java
- Java Swing
- Maven
- Object-Oriented Programming (OOP)
- File Handling
